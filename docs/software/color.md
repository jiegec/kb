# 色彩

## RGB

RGB 三种颜色，红绿蓝，每种颜色 0.0 到 1.0，或者 0 到 255。

## HSL

HSL，H（Hue）色相，S（Saturation）饱和度，L（Lightness）亮度。

直观上，H 代表它颜色在色环上的位置，S 代表它“颜色有多鲜艳”、距离灰色（R=G=B）有多远，L 代表它“颜色有多亮”、在黑色（R=G=B=0）到白色（R=G=B=1）的轴线上的位置。

H 是 0 到 360 度，S 是 0.0 到 1.0，L 也是 0.0 到 1.0。

对于 H，0 度对应红色，120 度对应绿色，240 度对应蓝色。

L 等于 RGB 三个分量里最大值和最小值的平均值。

## HSV

HSV，H（Hue）色相，S（Saturation）饱和度，V（Value）明度。

H 与 HSL 里的 H 一样。V 则是 RGB 三个分量里的最大值。S 的公式不同。
