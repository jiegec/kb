# 数独

## 强弱链

- 强链：某个位置等于某个数字（记为 A），与某个位置等于某个数字（记为 B），这两个命题至少有一个为真，则构成强链，A-强-B
- 弱链：某个位置等于某个数字（记为 B），与某个位置等于某个数字（记为 B），这两个命题至少有一个为假，则构成弱链，A-弱-B
- 性质：强弱交替（A-强-B-弱-C-强-D），则首尾也构成强链（A-强-D），证明如下：
    - 如果 A 是假，则 B 一定是真，C 一定是假，D 一定是真，此时 A 和 D 至少有一个为真
    - 如果 A 是真，那么无论 D 是真是假，A 和 D 至少有一个为真
    - 故 A-强-D 成立
- 根据归纳法，这个性质可以扩展到更长的链
